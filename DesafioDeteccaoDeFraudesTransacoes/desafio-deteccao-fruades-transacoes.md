# Projeto de Detecção de Fraudes em Transações Financeiras com Cartão de Crédito

O projeto executa a análise de um banco de dados de transações financeiras com cartão de crédito. Estes dados contém variáveis de valores de transação, horários e sinalizações de fraude.
A partir destes dados foram executados processos de leitura, limpeza e processamento dos dados para fazer treinamento de máquina com o objetivo de prever possível fraude em transações futuras.
Foram feitos teste com alguns modelos de treinamento, seguindo suas respectivas estruturas, análise de resultados e avaliando vantagens e desvantagens de cada pipeline.

## Modelos Usados
* Logistic Regression
* Random Forest
* XGBoost

## Verificação de Confiabilidade dos Modelos

Por fim, foram feitas análises dos resultados, comparações entre modelos e combinações para poder interpretar melhor como os modelos estavam lidando com os dados e a melhor forma de apresentar os resultados.
